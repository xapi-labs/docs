xAPI 提供两类面向 AI 应用的基础设施。**AI Gateway** 负责模型推理与多上游路由；
**Sandbox** 负责隔离计算、代码执行和实例生命周期。它们可以独立使用，也可以组合成
“模型负责规划，Sandbox 负责执行”的 Agent 工作流。

<CardGroup cols={2}>
  <Card title="AI Gateway" href="/ai/overview" icon="brain">
    统一调用 Claude、GPT、Gemini、DeepSeek、Kimi 等模型。兼容 Anthropic 与
    OpenAI 协议，提供多上游路由、流式响应、故障转移和 Token 计费。
  </Card>
  <Card title="Sandbox" href="/sandbox/overview" icon="terminal">
    创建隔离的临时云环境，执行命令、读写文件、暴露端口、运行 GPU 作业，
    并记录实例、操作、用量和结算历史。
  </Card>
</CardGroup>

## 两个产品域的边界

| | AI Gateway | Sandbox |
| --- | --- | --- |
| 核心目标 | 调用和路由大模型 | 运行代码和工作负载 |
| 主要入口 | `https://ai.xapi.to` | `https://sandbox.xapi.to` |
| 资源单位 | 模型请求、Token | 实例、CPU、内存、GPU、运行时间 |
| 生命周期 | 单次 HTTP / SSE / WebSocket 会话 | 报价、创建、执行、暂停、恢复、销毁 |
| 主要日志 | 模型、Token、延迟、费用、路由 | 操作、事件、用量段、账期、实例状态 |
| 常见客户端 | OpenAI/Anthropic SDK、IDE、AI 应用 | xAPI CLI、Agent Tool、OpenAI Agents Sandbox |

<Note>
  共用 API Key 不代表共用 API。调用模型时使用 AI Gateway；需要 Shell、文件系统、
  Web 预览或 GPU 时使用 Sandbox。
</Note>
